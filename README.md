# Гид студента ВГУ 📱🎓

**«Гид студента ВГУ»** — это кроссплатформенное мобильное приложение для студентов и абитуриентов Воронежского государственного университета, разработанное на базе фреймворка **Flutter** и языка **Dart**. 

Приложение работает полностью автономно (офлайн) и помогает первокурсникам быстрее адаптироваться к инфраструктуре вуза, а абитуриентам — оценить шансы на поступление.

---

## ✨ Ключевые возможности

* **🗺️ Интерактивный справочник корпусов:** Полный список учебных корпусов ВГУ с адресами, факультетами и кафедрами.
* **🏢 Справочник общежитий:** Информация обо всех студенческих общежитиях ВГУ, контакты комендантов, актуальные тарифы на проживание (для бюджетной/контрактной основы) и распределение квот мест по факультетам.
* **📊 Калькулятор абитуриента:** Ввод баллов ЕГЭ по предметам для автоматической фильтрации и подбора направлений.
* **📈 Статистика поступления:** Проходные баллы прошлых лет, планы приема и интерактивная визуализация квот (целевая, особая, отдельная и основной конкурс).
* **🌓 Адаптивный дизайн:** Современный интерфейс на базе **Material Design 3** с полной поддержкой светлой и темной тем, а также плавными анимациями переходов.
* **💾 Офлайн-режим:** Быстрый доступ к справочным данным без постоянного подключения к Интернету благодаря локальному кэшированию.

**📱 Установка готового APK**

1. Перейдите в раздел **[Releases](https://github.com/Almiton/student-guide/releases)** на странице этого репозитория.
2. Найдите последнюю версию (с тегом `Latest`).
3. В блоке **Assets** выберите и скачайте APK-файл, подходящий для вашего устройства (см. шпаргалку ниже).
4. Установите приложение (если потребуется, разрешите установку из неизвестных источников).

---
   
**📋 Описание файлов установки (APK):**

**StudentGuide.apk (~48.2 MB) — 📦 УНИВЕРСАЛЬНЫЙ**
Содержит поддержку всех архитектур процессоров сразу. Выберите его, если вы не знаете характеристики своего устройства или если другие APK-файлы выдают ошибку при установке.

**StudentGuide-arm64-v8a-release.apk (~17.0 MB) — 🌟 РЕКОМЕНДУЕТСЯ**
Для всех современных смартфонов.

**StudentGuide-armeabi-v7a-release.apk (~14.6 MB)**
Для устаревших или бюджетных Android-устройств с 32-битными процессорами ARM.

**StudentGuide-x86_64-release.apk (~18.4 MB)**
Специальная сборка для запуска и тестирования приложения в эмуляторах на ПК
