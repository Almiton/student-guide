# Гид студента ВГУ 📱🎓

**«Гид студента ВГУ»** — это кроссплатформенное мобильное приложение для студентов и абитуриентов Воронежского государственного университета, разработанное на базе фреймворка **Flutter** и языка **Dart**. 

Приложение работает полностью автономно (офлайн) и помогает первокурсникам быстрее адаптироваться к инфраструктуре вуза, а абитуриентам — оценить шансы на поступление.

---

## ✨ Ключевые возможности

* **🗺️ Интерактивный справочник корпусов:** Полный список учебных корпусов ВГУ с адресами, факультетами и кафедрами. Интеграция с внешними навигаторами (Яндекс Карты, 2ГИС, Google Maps) для быстрого построения маршрутов.
* **🏢 Справочник общежитий:** Информация обо всех студенческих общежитиях ВГУ, контакты комендантов, актуальные тарифы на проживание (для бюджетной/контрактной основы) и распределение квот мест по факультетам.
* **📊 Калькулятор абитуриента:** Ввод баллов ЕГЭ по предметам для автоматической фильтрации и подбора направлений бакалавриата и специалитета.
* **📈 Статистика поступления:** Проходные баллы прошлых лет, планы приема и интерактивная визуализация квот (целевая, особая, отдельная и основной конкурс).
* **🌓 Адаптивный дизайн:** Современный интерфейс на базе **Material Design 3** с полной поддержкой светлой и темной тем, а также плавными анимациями переходов.
* **💾 Офлайн-режим:** Быстрый доступ к справочным данным без постоянного подключения к Интернету благодаря локальному кэшированию.



## 🚀 Быстрый старт

Для запуска проекта на локальном компьютере убедитесь, что у вас установлен [Flutter SDK](https://docs.flutter.dev/get-started/install).

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Almiton/student-guide.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd student-guide
   ```
3. Скачайте зависимости:
   ```bash
   flutter pub get
   ```
4. Запустите приложение на подключенном устройстве или эмуляторе:
   ```bash
   flutter run
   ```
